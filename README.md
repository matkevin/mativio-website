# mativio-website
Mativio for Property Rental Solutions

A static site: open `index.html` in a browser. No build step.

- `index.html` — the page (styles, listings data and scripts are inline)
- `assets/logo.png` — the Mativio logo

Listings live in the `P` array near the top of the `<script>` in `index.html`; edit that to add or change homes.
